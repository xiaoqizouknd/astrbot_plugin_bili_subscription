# B站订阅推送

按你配置的间隔检查 B 站账号的最新动态、视频、专栏，推送到指定群。

## 三步用起来

1. **插件配置 → 管理员白名单**：填你的 QQ 号或群号（必填，否则管理命令全禁用）。
2. **插件配置 → 订阅列表**：点“添加”，每行只填「B站UID」和「群号」两栏。
   - UID 从 `space.bilibili.com/2267573` 里取数字部分。
   - 群号可以填纯数字，也可以填完整会话 ID。
   - 可选填「推送类型」和「检查间隔分钟」，留空用全局默认。
3. **建议**：装 `astrbot_plugin_bili_player` 并扫码登录 B 站，
   部分 UP 主的动态接口需要登录。

> 也可以不进 WebUI：管理员直接在群里发 `订阅 2267573` 即可添加订阅。

## 依赖

- `ffmpeg`：视频推送需要；未装则自动跳过视频，只推动态和专栏。
- `Pillow`：合成卡片需要；未装则动态/专栏无法发送。

## 管理命令（仅白名单用户）

- `订阅 <UID> [群号] [类型] [间隔分钟]` — 在聊天里添加订阅
  - `订阅 2267573`：订阅到当前会话（默认类型/间隔）
  - `订阅 2267573 123456789 视频,动态 30`：指定群、类型、间隔
- `退订 <UID>` — 移除当前会话的运行时订阅；`退订 <UID> all` 全部移除
- `订阅状态` — 查看订阅、登录状态、依赖健康、静音时段
- `订阅干跑` — 抓取 + 渲染，不发送，用来排查
- `订阅检查` — 立即执行一次检查
- `订阅测试 [UID]` — 向当前会话推最新一条动态和专栏
- `订阅诊断 [UID]` — 打印抓取结果和状态文件

## 其他特性

- **静音时段**：配置里开启后（如 23:00-07:00）暂停一切检查与推送，
  时段结束后自动补推，晚上不再被消息打扰。
- **防风控**：请求节流 + 随机抖动、WBI 签名自动刷新、bili_ticket 每天续期、
  登录态每小时检测、指数退避重试，尽可能保持低调稳定的抓取节奏。
  连续遭遇风控时自动进入 15 分钟冷却期（熔断），期间暂停所有后台请求，
  冷却结束自动恢复，不会在封禁期间继续硬刚。
- **视频推送**：按配置清晰度下载（自动选择不超过所选档位的最高可用画质），
  超过大小预算或下载失败自动降级为封面卡片，保证信息不丢。
- **专栏配图**：专栏卡片自动带封面 + 正文插图（最多 6 张）。
- **拼图还原**：图文动态里九宫格/四宫格/长图切片，卡片会自动拼回一张大图展示。
- **内容过滤**：默认跳过视频动态、空动态、以及**转发的动态**，只推 UP 主自己的内容；
  都可在配置里单独开关。
- **动图支持**：GIF 动图放进合并转发（聊天记录）里原样发送，保留动画；
  卡片合成图里仍会显示动图的第一帧作为预览。
- **多语言渲染**：卡片自动按「中文 → 韩文 → 日文 → emoji」回退系统字体，
  韩文/日文/emoji 不再显示为方框；也可在配置里指定全量字体（如思源黑体）。

## 注意

- 改配置后**无需重启**，下一次扫描自动生效。
- 首次检查某 UID 只记录“当前最新”，不推历史内容。
- 推送失败的条目会自动重试；连续失败 3 次后跳过。
