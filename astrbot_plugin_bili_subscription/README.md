# B站订阅推送

按你配置的间隔检查 B 站账号的最新动态、视频、专栏，推送到指定群。

## 三步用起来

1. **插件配置 → 管理员白名单**：填你的 QQ 号或群号（必填，否则管理命令全禁用）。
2. **插件配置 → 订阅列表**：点“添加”，每行只填「B站UID」和「群号」两栏。
   - UID 从 `space.bilibili.com/2267573` 里取数字部分。
   - 群号可以填纯数字，也可以填完整会话 ID。
   - 可选填「推送类型」和「检查间隔分钟」，留空用全局默认。
3. **建议**：装 `astrbot_plugin_bili_player` 并扫码登录 B 站，
   部分 UP 主的动态接口需要登录。

> 也可以不进 WebUI：管理员直接在群里发 `订阅 2267573` 即可添加订阅。

## 依赖

- `ffmpeg`：视频推送需要；未装则自动跳过视频，只推动态和专栏。
- `Pillow`：合成卡片需要；未装则动态/专栏无法发送。

## 管理命令（仅白名单用户）

- `订阅 <UID> [群号] [类型] [间隔分钟]` — 在聊天里添加订阅
  - `订阅 2267573`：订阅到当前会话（默认类型/间隔）
  - `订阅 2267573 123456789 视频,动态 30`：指定群、类型、间隔
- `退订 <UID>` — 移除当前会话的运行时订阅；`退订 <UID> all` 全部移除
- `订阅状态` — 查看订阅、登录状态、依赖健康、静音时段
- `订阅干跑` — 抓取 + 渲染，不发送，用来排查
- `订阅检查` — 立即执行一次检查
- `订阅测试 [UID]` — 向当前会话推最新一条动态和专栏
- `订阅诊断 [UID]` — 打印抓取结果、状态文件和推送台账
- `订阅撤回 <UID> [条数]` — 撤回该 UID 最近推送的消息（默认 3 条），
  用来手动清理已经发出去的重复内容

## 其他特性

- **静音时段**：配置里开启后（如 23:00-07:00）暂停一切检查与推送，
  时段结束后自动补推，晚上不再被消息打扰。
- **绝不重复推送**：插件会持久化一份「推送台账」（`push_ledger.json`），
  按「内容 ID + 会话」精确记账——
  - 同一条动态/视频/专栏对同一个群**只会发出一次**；
  - 重启插件、重载插件都不会重发（台账在磁盘上，不在内存里）；
  - 两次检查之间一次涌出很多条内容时，也不会把窗口里的旧内容重推一遍；
  - 记录每条消息的实际消息 ID，一旦发现同一条内容被重复发出，
    会**自动撤回**多出来的消息（可用「检测到重复推送时自动撤回」关闭）。
  发送失败只记日志、不重发（平台常出现"消息已送达却回报失败"）；
  若你更看重送达率，可在配置里打开「推送失败自动重试」。
- **防风控**：请求节流 + 随机抖动、WBI 签名自动刷新、bili_ticket 每天续期、
  登录态每小时检测、指数退避重试，尽可能保持低调稳定的抓取节奏。
  连续遭遇风控时自动进入冷却期（熔断，默认 15 分钟，可配置），
  期间暂停所有后台请求；反复被封时冷却自动逐级翻倍（最长 2 小时），
  不会在封禁期间继续硬刚。
  B 站动态 feed 接口偶发返回空列表（同样的请求会 0 条/正常交替），
  插件会对空返回重试，不会把这种抖动当成"没有新内容"而漏推。
- **视频推送**：按配置清晰度下载（自动选择不超过所选档位的最高可用画质），
  超过大小预算或下载失败自动降级为封面卡片，保证信息不丢。
- **专栏配图与全文**：一次请求同时取回专栏的**正文全文**与**正文插图**；
  抓不到正文时才退回列表接口的摘要 + 封面兜底。
- **正文补齐**：B 站接口会把「专栏动态」的正文图片替换成 `[图片]` 占位符、
  并把正文截断（`has_more`）。插件在推送前会按需抓一次 opus 网页，
  把**完整正文**和**全部正文图片**补齐（同一张图在不同接口里可能一个是
  `http://`、一个是 `//`，插件会按图片路径去重，不会重复画）。
  该行为默认开启，可用「补齐正文」开关关闭（代价是正文图/全文可能缺失）。
- **多图排版**：
  - 「图文动态」的相册图按 B 站的网格规则排布（1 张整宽、2/4 张两列、
    3/5~9 张三列），也就是原动态里"几张小图拼成一张大图"的观感；
  - 「专栏动态」的正文长图整宽单列（和 B 站正文一致，长图里的字才看得清）；
  - 不再猜测"几张独立图是同一张大图的切片"去竖拼/横拼——那种猜测在多张
    同宽的独立长图上必然误判，会把卡片压成一条看不清的小图。
- **动态一条卡片**：卡片自带**完整正文** + 排好版的图片，卡片宽度 860px 保持适中；
  原图默认同时放进合并转发（聊天记录）这一条折叠消息里，方便放大看长图，
  觉得多余可用「原图同时发聊天记录」关掉。
- **内容过滤**：默认跳过视频动态、空动态、以及**转发的动态**，只推 UP 主自己的内容；
  都可在配置里单独开关。
- **动图支持**：GIF 动图放进合并转发（聊天记录）里原样发送，保留动画；
  卡片合成图里仍会显示动图的第一帧作为预览。
- **多语言渲染**：卡片自动按「中文 → 韩文 → 日文 → emoji」回退系统字体，
  韩文/日文/emoji 不再显示为方框；也可在配置里指定全量字体（如思源黑体）。

## 注意

- 改配置后**无需重启**，下一次扫描自动生效。
- 首次检查某 UID 只记录“当前最新”，不推历史内容。
- 连续发送失败 3 次的条目会被跳过，避免坏条目卡住后面的内容。
- 撤回受平台限制：QQ 只允许撤回 2 分钟内的消息，超时的撤回会被拒绝
  （日志里会写明原因）。

## 开发自测

仓库根目录的 `tests/` 下有不需要 AstrBot 运行时的自测脚本，
改完推送/去重逻辑后可以直接跑：

```bash
python tests/test_dedup.py        # 去重、台账、状态文件持久化、自动撤回
python tests/test_send_path.py    # 发送路径、消息 ID 捕获、撤回调用
python tests/test_risk_control.py # 风控冷却、重试次数
python tests/test_body_enrich.py  # 正文补齐、opus 网页解析、多图排版
```
